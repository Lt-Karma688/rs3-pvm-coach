# RS3 PvM Coach (Alt1)

Informational RuneScape 3 PvM coaching overlay built for Alt1.

## Current proof of concept
- Vindicta & Gorvek Normal Mode profile
- Alt1 pixel capture
- Alt1 overlay callouts
- Gorvek purple fire-wall detector
- Manual rotation/phase coach
- Optional voice cues
- Debug/calibration UI

## Install
After GitHub Pages deploys, open the hosted page and click **Add to Alt1**, or use the hosted `appconfig.json` with Alt1.

The app only requests `pixel,overlay` permissions and does not generate game input.
